# 大盤籌碼

> 位置：頂部選單「大盤籌碼」（網址 `/market`，預設開啟「大盤籌碼」分頁）
> 資料更新：依分頁不同，見各分頁開頭的「資料更新」

## 這個功能可以做什麼
「大盤籌碼」集中看整個市場：開盤前的盤前摘要，加權、櫃買指數與外資期貨、三大法人、融資等大盤籌碼，市場強弱的綜合分數，盤中的指數走勢與產業強弱，個股的各種排行，當天的除權息與處置等事件，族群資金流向，國際總經（匯率、央行利率、原物料、美國公債、恐懼與貪婪、美股指數的長期走勢與統計），主動 ETF 的持股增減，權值股的指數貢獻，以及權證的資金排行。

## 共通說明
- 數字顏色：漲、買超、增加用漲色，跌、賣超、減少用跌色（顏色可在設定頁調整）；每個數字都有正負號，不只靠顏色。
- 標「估」的是估計值，滑過「估」可看計算方式；標「暫定」的是收盤前或資料尚未到齊的暫時結果。
- 有些分頁的選擇（例如「大盤籌碼」的指數、期間與副圖，「即時大盤」的成分股清單）記在這台電腦的瀏覽器，換一台電腦或清除瀏覽器資料後回到預設值。
- 表格可以點欄名排序的，排序只排目前畫面上已取回的列。
- 點股票代號名稱會開啟個股分析頁。
