# 快捷鍵

> 位置：任何頁面按 `?`（Shift + /），或點頁尾的「快捷鍵」，打開「快捷鍵一覽」視窗
> 資料更新：不需要資料

## 這個功能可以做什麼
把全站可以用的鍵盤快捷鍵集中在一個視窗，不用記每一頁的說明。這一頁的表格與視窗的內容相同。

## 操作步驟
1. 在任何頁面按 `?`（Shift + /），打開「快捷鍵一覽」。
2. 按 Esc、再按一次 `?`，或點視窗右上角的關閉鈕關閉。
3. 也可以點頁尾最右邊的「快捷鍵」打開。

游標在輸入框、選單或對話框內時，快捷鍵不作用（頂部搜尋框內的按鍵除外），所以在輸入框打 `?`、`[`、數字都是一般輸入。

## 快捷鍵一覽

### 全站
| 按鍵 | 動作 |
|---|---|
| `?` | 打開或關閉快捷鍵一覽 |
| `/` | 把游標移到頂部搜尋框 |

### 頂部搜尋框（游標在搜尋框內）
| 按鍵 | 動作 |
|---|---|
| `↑`／`↓` | 在下拉清單中選擇上一項、下一項 |
| `Enter` | 進入選取的股票或分點；輸入合法的股票代號時直接進入 |
| `Esc` | 關閉下拉清單；清單已關閉時離開搜尋框 |

### 個股頁
| 按鍵 | 動作 |
|---|---|
| `[` | 切到前一個分頁（依分頁列目前的順序，跳過隱藏的分頁，到第一個時接到最後一個） |
| `]` | 切到下一個分頁（到最後一個時回到第一個） |
| `↑`／`↓` | 目前的股票在「自選股」頁選取的群組中時，切換到群組的上一檔、下一檔，留在同一個分頁 |

分頁的順序可以在分頁列最右邊的「調整分頁」改，見[個股分析｜調整分頁](stock/README.md#調整分頁)。

### K 線圖（K線籌碼圖、分點進出圖、大盤籌碼、期貨）
| 按鍵 | 動作 |
|---|---|
| `←`／`→` | 移動十字線 |
| `Esc` | 十字線回到最新一根；在K線籌碼圖分頁同時取消鎖定的結束日與自訂區間 |
| `Alt + R` | 重設圖表視圖 |

### K線籌碼圖分頁
| 按鍵 | 動作 |
|---|---|
| `1～8` | 切換統計天數（依序為 1、3、5、10、20、60、120、240 日） |
| `Delete`／`Backspace` | 刪除選取的繪圖（鎖定的繪圖不刪除） |
| `Ctrl + Z` | 復原繪圖 |
| `Ctrl + Y`／`Ctrl + Shift + Z` | 重做繪圖 |
| `Esc` | 依序關閉繪圖選單、取消放置中的繪圖工具、取消選取的繪圖，都沒有時才回到最新一根 |

### 回放分頁
| 按鍵 | 動作 |
|---|---|
| `空白鍵` | 播放／暫停 |
| `←`／`→` | 上一分鐘／下一分鐘 |

### 自選股頁（表格檢視）
| 按鍵 | 動作 |
|---|---|
| `↑`／`↓` | 選擇上一檔、下一檔 |
| `Enter` | 開啟選取那一檔的個股頁 |

## 注意事項與限制
- macOS 的 Ctrl 組合鍵也可以用 Command，Alt + R 也可以用 Option + R。
- 手機寬度不顯示頁尾的「快捷鍵」；手機接上實體鍵盤時按 `?` 仍可打開。
- 中文輸入法選字時按的鍵屬於輸入法，不當成快捷鍵。
