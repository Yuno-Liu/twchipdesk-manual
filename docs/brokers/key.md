# 分點研究｜關鍵分點

> 位置：頂部選單「分點研究」→「關鍵分點」分頁（網址 `/brokers/key`，例如 `/brokers/key?days=5`）
> 資料更新：查詢時依已匯入的分點資料即時計算；結束日為最近一個分點資料完整的交易日（每個交易日 18:10 起匯入，全部匯入完成後才會成為結束日）

## 這個功能可以做什麼
為每檔股票指定自己要追蹤的「關鍵分點」（一檔股票可以有多個），統計這些分點在該股一段期間的買張、賣張、買賣超、均價、名次、連續買賣天數等。適合同時追蹤很多組「股票＋分點」，並用排序與搜尋快速找出有動靜的組合。

「關鍵分點」是你自己指定的清單，和「重要分點」（全市場分類）、個股分點進出圖上每晚計算的「關鍵分點標籤」（囤、出、作…）都不一樣。

## 畫面說明

| 編號 | 名稱 | 說明 |
|---|---|---|
| 1 | 說明 | 這個分頁的用途。 |
| 2 | 「新增關鍵分點」 | 逐筆新增（見下方操作步驟）。 |
| 3 | 「整批匯入」 | 貼上清單一次新增多筆。 |
| 4 | 「統計天數」 | 1、3、5、10、20、60 日（交易日），預設 1 日。 |
| 5 | 「自訂」 | 輸入 1～240 的任意天數。 |
| 6 | 搜尋框 | 依股票或分點的代號、名稱篩選表格（分點代號區分大小寫）。 |
| 7 | 期間與組數 | 實際起訖日、交易日數，以及「顯示組數／全部組數」。切換天數時舊資料仍顯示，起訖日後面會出現「（更新中）」。 |
| 8 | 展開按鈕 | 展開這組的逐日明細（見下圖）。 |
| 9 | 「刪除」 | 刪除這組關鍵分點，會先跳出確認視窗。 |

全部欄名都可以點擊排序（遞減、遞增、回到預設順序）；預設依股票代號、分點代號排列。

### 逐日明細

展開後列出期間內每一天的「買張」「賣張」「買賣超」「買均價」「賣均價」「收盤」「漲跌幅」與「當日排名」；當天沒有這檔股票的分點資料時顯示「無分點資料」。

## 操作步驟

### 逐筆新增
1. 按「新增關鍵分點」。
2. 在「搜尋股票代號或名稱」選股票，在「搜尋分點代號或名稱（代號區分大小寫）」選分點；選好後下方顯示「股票：…」「分點：…」。
3. 需要時填「備註」（最多 200 字）。
4. 按「加入」，畫面顯示「已加入 股票 的關鍵分點 分點」。同一組已存在時顯示「這檔股票已有這個關鍵分點」。

### 整批匯入
1. 按「整批匯入」。
2. 貼上 TSV（tab 分隔，可直接從試算表複製）或 CSV 文字。第一列可以是表頭（股票代號、股票名稱、關鍵分點、關鍵分點代號、備註）；沒有表頭時依序為股票代號、分點代號、備註。名稱欄只用來核對，以代號為準。
3. 按「預覽」，每列顯示狀態：「可新增」「已存在」「股票不存在」「分點不存在」「格式錯誤」，名稱與資料庫不同時在「核對」欄提示。
4. 確認無誤後按「確認匯入（新增 N 組）」。一次最多 2,000 列；預覽後修改文字會清掉舊的預覽。

### 查看與篩選
1. 選「統計天數」或在「自訂」輸入天數；天數存在網址（`?days=5`）。
2. 在搜尋框輸入股票或分點的代號、名稱篩選。
3. 點欄名排序，例如依「買賣超佔成交量」找出比重最大的組合。

## 欄位與名詞
- **買張**、**賣張**、**買賣超**：期間內這個分點在這檔股票的買入、賣掉與淨買賣張數。
- **買均價**、**賣均價**：期間內以股數加權的買入、賣掉均價。
- **買賣超金額（估）**：買入股數 × 當日買均價 − 賣掉股數 × 當日賣均價，逐日加總。
- **買賣超佔成交量**：淨買賣股數 ÷ 該股期間成交量（只計分點資料完整的日子），保留正負號；滑鼠停在數字上顯示買張佔成交量。
- **排名**：這個分點在這檔股票期間內所有分點中的名次（「買超第 N 名」或「賣超第 N 名」，同值同名次）；滑鼠停在上面顯示期間買超、賣超各有幾家分點。
- **買超天數**、**賣超天數**：期間內買入多於、少於賣掉的交易日數。
- **連續天數**：從結束日往回數，連續同方向的天數（「連買 N 天」或「連賣 N 天」）；沒有交易或買賣相等的日子會中斷。
- **收盤**、**區間漲跌**：結束日收盤（漲停、跌停以底色標示）與期間漲跌幅（以起日前一個收盤為基準）。
- **涵蓋率**：期間內該股有完整分點資料的交易日比例；不足 100% 時顯示 ⚠，滑鼠停在上面說明缺幾天。

## 資料來源與更新時間
- 清單存在伺服器上；設定頁的匯出與匯入（備份）包含個股關鍵分點。
- 新增、刪除、匯入後，策略選股的關鍵分點相關欄位會在背景重算受影響的股票。

## 注意事項與限制
- 分點代號區分大小寫，例如 9A9C（永豐金-員林）與 9A9c（永豐金-永康）是不同分點；搜尋清單同時顯示代號與名稱，請對照後選擇。
- 每晚分點資料匯入中（18:10 起到匯入完成）結束日不會跳到當天，仍是前一個完整的交易日。
- 金額與均價是用分點每天的均價推算，標「估」。
- 分點不代表最終持有人，見[分點研究總覽](README.md)。

## 常見問題
- **為什麼有些列全部是 0？** 那個分點在期間內沒有買賣這檔股票。
- **和「自選分點組合」有什麼不同？** 兩者都是「股票＋分點」清單；關鍵分點有更多統計欄位、可自訂天數與整批匯入，自選分點組合顯示最新一日、近 5 日與 60 日損益。
