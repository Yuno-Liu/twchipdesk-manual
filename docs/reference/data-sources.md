# 資料來源與更新時間

這一頁整理系統每一類資料從哪裡來、每天幾點更新。時間都是台北時間；「交易日」指週一至週五的開市日。實際執行情形可在 [系統（資料狀態）](../system.md) 的「排程工作」與「資料集狀態」查看。

| 公司地址（地緣分點、地緣地圖用） | 臺灣證券交易所 OpenAPI 等政府開放資料 | 公司基本資料外掛啟用時每週更新，也可在設定頁匯入或手動補座標。 |
| 自選股、持股、策略、看盤室版面、關鍵分點等 | 使用者輸入 | 存在本機服務的資料庫，可在設定頁「資料維護」匯出與匯入。 |

籌碼明細「槓桿總覽」各區塊的來源：融資、融券、借券賣、券源的融券剩餘額度與次日借券賣可用額度來自融資融券與借券資料（FinMind，21:05）；融資維持率（估）與融資成數來自融資維持率資料（22:35）；不限用途借貸、當沖券差借券（21:20）與借券成交明細（20:30）來自 FinMind 的信用延伸與借券成交資料；當沖量與當沖比來自當沖量值與日 K（21:35）；停止融券期間來自暫停融券資料（21:05）；股票期貨來自期權商品主檔與期貨日資料（15:20 起），近月價差來自本系統的期現價差計算（19:00）；權證存續檔數、成交金額與投資人淨買約當張數（估）來自權證主檔、權證日行情與權證投資人淨買（個股三大法人之後）；發行股數取外資持股資料裡的發行股數。見[個股分析｜籌碼明細](../stock/detail.md#槓桿總覽)。

[個股分析｜走勢比較](../stock/compare.md)（大盤籌碼、族群頁下方嵌入的也是同一個）各項目的來源：個股與 ETF 用日 K（未還原的收盤與參考價，17:35；交易時段內每分鐘加上即時點）；加權、櫃買與官方類股指數用指數日資料（與全市場日 K 一起入庫），含息時加權、櫃買改用含息報酬指數（17:40）；族群是本系統以目前成分股等權計算的指數，停在前一個交易日；國際項目用國際行情（07:50，依台股交易日對齊）。「籌碼」子分頁用三大法人（20:05）、主力（分點資料 18:10 之後計算）與融資融券（21:05）；「基本面」子分頁用月營收（18:30、22:00）、本益比、股價淨值比與殖利率（18:05）與財報（19:00）。

本系統計算出來的數字（主力、散戶（估）、預估量、權證約當淨買、處置機率等）的定義寫在各功能的說明與畫面上的「資料說明」。

## 注意事項
- 時間是排程開始的時間；資料來源晚發布時，部分工作會自動重試，實際入庫時間可能更晚。
- 非交易日不執行交易日的排程（標「每天」的除外）。
- 颱風等臨時休市可在設定頁「交易日曆」標記，系統會修正已寫入的資料。
- 只能手動執行的一次性回補與重算工作（例如歷史回補、依新規則重算）列在資料狀態頁的「排程工作」，說明欄會寫明。
