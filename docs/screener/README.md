# 策略選股

> 位置：頂部選單「策略選股」（網址 `/screener`）
> 資料更新：盤後條件用每個交易日晚上計算的選股特徵（23:50 分點研究完成後以當晚全部資料重算）；盤中條件與即時訊號在盤中即時更新

## 這個功能可以做什麼
用 344 條價量、技術、籌碼、法人、資券、大戶、基本面、事件、權證、型態、大盤與盤中條件組出選股策略，找出符合的股票；也可以回溯過去的報酬、模擬投資組合、追蹤紙上帳戶，並統計各策略、型態與盤中訊號過去的表現。所有結果都是資料篩選與歷史統計，不構成任何投資意見。

## 分頁
| 分頁 | 網址 | 用途 |
|---|---|---|
| [「策略選股」](screener.md) | `/screener` | 建立與執行策略：條件群組、時間修飾、範圍與排序、盤後／盤中模式、單日與區間結果、族群統計、回溯；「用一句話選股」與結果的「說明」（[AI 助手](../assistant/README.md)）。 |

| [「組合與紙上」](portfolio.md) | `/screener/portfolio` | 2～5 個策略的組合回測，以及每晚自動更新的紙上帳戶。 |
| [「訊號績效」](signal-stats.md) | `/screener/signal-stats` | 策略、技術型態與盤中訊號出現後持有 1～20 日的歷史報酬統計。 |

參考：[條件總表](conditions.md)列出全部條件的參數、單位與說明。

## 常見的使用流程
1. 在[內建策略庫](library.md)找一個接近需求的策略，按「套用」看今天的結果。
2. 在[選股](screener.md)頁調整條件與範圍，「另存為我的策略」。
3. 用「回溯」或「區間」統計看過去的結果，再按「在實驗室開啟」做[投資組合模擬](lab.md)。
4. 需要持續追蹤時建立[紙上帳戶](portfolio.md#紙上帳戶)；累積一段時間後到[訊號績效](signal-stats.md)比較各策略。
