# 反轉價位

> 位置：頂部選單「反轉價位」（網址 `/reversal`，預設開啟「盤後清單」分頁）
> 資料更新：每個交易日 14:10 收盤資料入庫後計算當天與下一個交易日的價位；週日 03:30 全部重算

## 這個功能可以做什麼
每檔股票的股價離 20 日均線多遠（乖離），各有自己的習慣範圍。本功能用每檔股票自己過去 5 年的乖離分布，找出「通常不會再更低」的負乖離（地板）與「通常不會再更高」的正乖離（天花板），再換算成每天的「地板價」與「天花板價」，並統計過去碰到這兩個價位之後幾天的漲跌。

- [盤後清單](list.md)：收盤後列出小於地板、近於地板、近於天花板、大於天花板的股票，附每檔的歷史回測摘要；也可看下一個交易日的地板價、天花板價。
- [盤中監控](live.md)：盤中即時價與今日地板價、天花板價的距離，標出觸及與接近的股票。
- [回測統計](backtest.md)：個股或全市場的地板訊號、天花板訊號之後 1、3、5、10、20 日的統計。
- 個股頁：K線籌碼圖的「地板天花板」圖層與頁首下方的小卡，見[個股分析｜K線籌碼圖](../stock/kline.md)。

所有地板價、天花板價都是歷史統計的估計值（標「估」），不代表之後的價格會停在範圍內；歷史統計不代表未來結果。頁面最下方固定有這段說明。

## 先認識幾個名詞
| 名詞 | 意思 |
|---|---|
| 乖離 | (收盤 − 20 日均線) ÷ 20 日均線。用還原收盤計算，除權息、減資不會造成假的大跌 |
| 地板門檻 | 這檔股票在當天以前 5 年（1,250 個交易日）的負乖離中，最負的第 5 百分位 |
| 天花板門檻 | 同一段期間正乖離的第 95 百分位 |
| 地板價（估） | 當天收盤剛好讓乖離等於地板門檻的價格；往下取到升降單位 |
| 天花板價（估） | 當天收盤剛好讓乖離等於天花板門檻的價格；往上取到升降單位 |
| 量比 | 當天成交量 ÷ 前 20 個交易日平均成交量（不含當天） |
| 地板訊號 | 收盤小於或等於地板價（預設還要量比 2 倍以上）；連續期間只算一次（規則見[回測統計](backtest.md)） |
| 天花板訊號 | 收盤大於或等於天花板價（條件同上） |

門檻只用當天以前的資料計算，回測不會用到未來的資料。有效乖離少於 250 筆的股票標「資料不足」，不列入清單與回測。

**四類分類**（以收盤價判斷，「近於」距離預設 2%）：

| 分類 | 條件 |
|---|---|
| 「小於地板」 | 收盤 ≤ 地板價 |
| 「近於地板」 | 地板價 < 收盤 ≤ 地板價 × (1 + 2%) |
| 「近於天花板」 | 天花板價 × (1 − 2%) ≤ 收盤 < 天花板價 |
| 「大於天花板」 | 收盤 ≥ 天花板價 |

## 資料來源與更新時間
- 日 K、還原價來自 FinMind；每個交易日 14:10 後計算當天的分類與下一個交易日的地板價、天花板價（盤前就看得到）。
- 第一次啟用時會在背景回補 2010 年以來的資料；回補完成前，頁面顯示「反轉價位資料還在建立中」。

## 注意事項與限制
- 門檻來自歷史分布：長期下跌的股票會頻繁出現地板訊號，請同時看回測統計的逐年結果與超額報酬。
- 當天沒有成交、上市未滿 250 個交易日的股票不列入清單。全額交割股目前沒有資料來源，尚未排除。
- 本功能只整理歷史統計，不提供任何操作意見。

## 在策略選股使用

策略選股的「技術」分類有三條地板天花板條件：距地板價（估）、距天花板價（估）與地板天花板分類（估），值取自本頁每天算好的價位（以資料日收盤對下一個交易日的地板價、天花板價），可以和其他條件一起篩選、回溯。說明見[策略選股｜條件總表](../screener/conditions.md#技術40-條)。
