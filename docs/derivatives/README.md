# 期權

> 位置：頂部選單「期權」（網址 `/derivatives`，預設開啟「期現價差」分頁）
> 資料更新：期貨、選擇權日資料與三大法人 15:20 起（不足時每 10 分鐘重試到 18:30）；大額交易人 15:30 起；最後結算價 17:30；晚間補抓 18:10；每日收盤價差、預估除息點數與選擇權 IV 等衍生資料 19:00；期貨商成交量 20:45。盤中由券商即時行情推送

## 這個功能可以做什麼
期權模組整理期貨與選擇權的行情與籌碼：期貨與現貨的價差、扣成本後的期現淨價差（估）、各期貨商品的 K 線與未平倉、選擇權 T 字報價與 IV、法人與大額交易人部位，以及每個到期日的結算日曆。所有內容只提供資訊；標「估」的數字為推算值。

## 共通說明
- **盤後與盤中**：盤後的數字以每日收盤資料計算，頁面標「盤後資料」與資料日；交易時段內，「期現價差」「期貨」「選擇權」會以券商即時行情更新，並標示來源（「富邦即時」「玉山即時」，或券商即時未連線時的「FinMind 約 30 秒」）。
- **一般交易時段與夜盤**：期貨一般時段 08:45～13:45（現貨 09:00～13:30）；夜盤 15:00～次日 05:00（股票、ETF 期貨 17:25 起）。夜盤的交易算在**下一個交易日**。
- **估**：理論價差、超額價差、預估除息點數、夜盤隱含漲跌、推算的到期日（月契約為該月第三個星期三，遇休市順延）、套利的成本與淨額等都是估計值。
- **調整**：標的除權、現金增資或減資後改代號並調整約定股數的契約，標「調整」，不列入正逆價差家數與分布。
- **週**：週契約標「週」。
- **休市順延**：原定到期日休市（含颱風等臨時休市）時，最後交易日順延至次一交易日。
- 頁尾固定註明：期權資訊僅供研究參考；標「估」的數字為推算值。

## 模組關閉時
設定頁「期權」區的總開關關閉時，頂部選單不顯示「期權」；直接打開網址會看到「此功能已關閉」與「前往設定」連結（直接跳到設定頁的「期權」區塊），相關排程也不會執行。

## 名詞
| 名詞 | 意思 |
|---|---|
| 價差（基差） | 期貨價 − 標的價。期貨高於標的為「正價差」（紅色），低於為「逆價差」（綠色），價差% 絕對值小於設定的門檻（預設 0.02%）為「平」 |
| 理論價差（估） | 持有成本模型：標的 × 年利率 × 距結算日曆日數 ÷ 365 − 結算前除息的股利（指數為預估除息點數）；年利率預設 1.7%（設定頁「期權」區） |
| 超額價差（估） | 價差 − 理論價差；超額價差% = 超額價差 ÷ 標的收盤 × 100 |
| 年化% | 價差% 換算成一年的比例 |
| 近月 | 當天有成交、最早到期的月契約；結算日當天換為次月 |
| 未平倉 | 還沒有平倉的口數；盤中顯示的未平倉為前一交易日 |
| 預估除息點數（估） | 指數在結算前已知除息日的成分股現金股利換算成的指數點數；涵蓋率越低表示可能低估越多 |
| IV、Greeks | 選擇權的隱含波動率與 Delta、Gamma、Theta、Vega，以 Black-76 模型計算 |

## 資料來源與更新時間
| 時間（交易日） | 內容 |
|---|---|
| 07:50、17:00 | 期權商品主檔與期貨合約 |
| 15:20 起 | 期貨、選擇權日資料與三大法人、夜盤法人（列數不足時每 10 分鐘重試到 18:30） |
| 15:30 起 | 大額交易人 |
| 17:30 | 最後結算價（只查當天有到期合約的一邊） |
| 18:10 | 晚間補抓當日與前兩個交易日、波動率指數 |
| 19:00 | 每日收盤價差、預估除息點數、選擇權每日衍生資料（IV、Greeks、P/C、Max Pain 等） |
| 20:45 | 期貨商成交量 |
| 盤中 | 券商即時行情（富邦或玉山）；未連線時改用 FinMind 盤中快照（約 30 秒一次，只涵蓋部分商品） |

盤後資料來自 FinMind（期交所資料）。
