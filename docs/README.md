# TwChipDesk 使用手冊

這份手冊說明 TwChipDesk 每一個頁面、分頁與功能怎麼用：畫面上每個按鈕、欄位代表什麼，資料從哪裡來、什麼時候更新，以及有哪些限制。每個功能一個檔案，依頂部選單分資料夾，方便日後單獨修改。

> 本系統所有數字都是資料整理與統計結果，不構成任何投資意見。標「估」的是估計值，標「暫定」的是收盤前或資料尚未到齊時的暫時結果。

## 怎麼閱讀
- 每一頁開頭寫「位置」（從哪裡點進來、網址）與「資料更新」時間。
- 截圖上的橘色數字對應下方「畫面說明」表格的編號。
- 截圖來自實際畫面；左側自選欄在多數截圖中隱藏，個人持股等資料會模糊處理。
- 畫面上的文字以「」標示，例如「排行」分頁、「匯出 CSV」按鈕。
