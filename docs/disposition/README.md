# 處置雷達

> 位置：頂部選單「處置雷達」（網址 `/disposition`，預設開啟「處置日報」分頁）
> 資料更新：交易日 14:40 盤後初版；官方注意、處置名單取得後更新（預設 18:30、19:30、21:00 抓取）；22:10 定版；統計與處置配對在定版後重算

## 這個功能可以做什麼
處置雷達依證交所、櫃買中心公開的「注意交易資訊暨處置作業要點」，把每天的注意股、處置股整理成清單，並推算：

- 今晚哪些股票會被公布處置（明天起處置）。
- 明天哪些股票可能被處置，明天收盤到什麼價、成交量到多少張就會達到處置條件（處置觸發價、觸發量），以及機率（估）。
- 未來 3 個交易日，每天要達到的門檻（三日門檻）。
- 目前處置中的股票、何時出關。
- 處置股與同族群股票的價格比值（處置配對）。
- 新制以來每一次處置前後的逐日統計。

所有推算都依公開規則計算，僅供研究參考，一切以證交所、櫃買中心公告為準。

## 共通操作
- **資料日**：頁首右上角的「資料日」選擇要看的日子（不能選未來）；清除後為「最新」。資料日放在網址（`?date=2026-11-09`），切換分頁時會保留。「統計」分頁不使用資料日。
- 頁尾固定一行說明：依公開規則推算的結果，僅供研究參考，一切以證交所、櫃買中心公告為準。

## 先認識幾個名詞

### 注意與處置的流程
```
交易日 T 收盤
  │  T 晚上：交易所依 T 的交易資料公布「注意股」
  │  T 晚上：若 T 的注意讓某檔股票達到處置條件，同時公布「處置股」
  ▼
T 的次一營業日起處置 5 個營業日（含當沖標準者 7 個營業日；遇休市、停止買賣順延）
  ▼
處置期間最後一天的次一營業日「出關」
```

### 注意標準（各款）
交易所的注意標準共 14 款（第四條第一項）。本系統用到的重點：

| 款 | 白話 | 計入處置次數 |
|---|---|---|
| 第一款 | 最近 6 個營業日累積漲跌幅過大，且與全體、同類股平均的差幅也夠大 | 是 |
| 第二款 | 最近 30、60、90 個營業日的漲跌幅過大 | 是 |
| 第三款 | 6 日累積漲跌過大，且當日成交量放大到最近 60 日平均的數倍 | 是 |
| 第四款 | 6 日累積漲跌過大，且當日週轉率過高 | 是 |
| 第五款 | 6 日累積漲跌過大，且單一證券商成交占比過高 | 是 |
| 第六款 | 本益比或股價淨值比異常，且週轉率、成交量達標 | 是 |
| 第七款 | 6 日累積漲跌過大，且券資比放大 | 是 |
| 第八款 | 存託憑證（TDR）溢折價異常 | 是 |
| 第九至十四款 | 成交量放大、累積週轉率、高價股價差、借券、當沖比率、監視會報決議等 | 否（第十三款當沖會影響處置天數） |

實際的門檻數字（例如第一款上市為超過 32%、上櫃為超過 30%）見「[規則說明](rules.md)」分頁，以當天生效的規則版本為準。

### 處置條件
只有第一至八款的注意才計入。下面任一條件成立，當晚公布處置：

| 條件 | 畫面簡稱 | 白話 |
|---|---|---|
| 連續 3 日第一款 | 「連3」 | 連續 3 個營業日被公布第一款 |
| 連續 5 日注意 | 「連5」 | 連續 5 個營業日被公布第一至八款任一款 |
| 10 日內 6 日注意 | 「10日6次」 | 最近 10 個營業日內有 6 天被公布第一至八款 |
| 30 日內 12 日注意 | 「30日12次」 | 最近 30 個營業日內有 12 天被公布第一至八款 |

同一天被公布多款只算 1 天。

營業日以該股自己的交易日計算：該股全日暫停交易的日子不算營業日，連續次數與各款的累積期間（例如第一款的 6 日累積）都跳過這一天；整天沒有成交的日子仍算營業日。暫停交易的恢復日未定時，以恢復後第一個有成交的日子為止（冷門股可能多跳過幾天）。

### 處置措施（第一次與第二次以上）
- **第一次處置**：最近 30 個營業日內沒有被處置過。約每 2 分鐘撮合一次；單筆 10 張或多筆累計 30 張以上要預收款券。
- **第二次以上**：最近 30 個營業日內曾被處置。約每 2 分鐘撮合一次，全部委託預收款券。
- 處置期間 5 個營業日；同時符合當沖標準時延長為 7 個營業日（畫面標「含當沖」）。

以上為 2026-08-10 新制的數字；實際以「規則說明」分頁與官方公告為準。

### 本系統的推算用語
| 名詞 | 意思 |
|---|---|
| 注意日 | 被公布第一至八款任一款的交易日 |
| 距離 | 從明天起，最少還需要幾個注意日才會達到任一處置條件；「今晚處置」表示今晚就會公布 |
| 最近條件 | 距離最小的處置條件 |
| 處置觸發價 | 明天收盤價至少（上漲）或至多（下跌）到多少，就會讓這檔股票明天晚上被公布處置；假設明天大盤與同類股平均不漲不跌，只計第一、二款 |
| 觸發量 | 第三、四、六款需要價與量同時達標；觸發量是明天全日成交量（含零股、鉅額）要達到的張數 |
| 機率（估） | 明天晚上被公布處置的機率；依過去狀態相近的股票隔天的價量分配推算，並以最近 250 個交易日的實際結果校準 |
| 等級 | 依機率分級（見下表） |
| 出關 | 處置期間最後一天的次一個交易日 |
| 再處置窗口 | 出關後仍在「最近 30 個營業日內曾發布處置」範圍內的期間；這段期間再進處置就是第二次以上 |

**等級**（每個等級都有文字，不只靠顏色）：

| 等級 | 意思 |
|---|---|
| 「今晚處置」 | 今天收盤後處置條件已成立，今晚公布，明天起處置 |
| 「必關」 | 依規則，明天任何收盤價都會成立；除非官方另有決定或資料有誤，否則會被公布處置（或機率 ≥ 97%） |
| 「高」 | 明日處置機率（估）60%～97% |
| 「中」 | 明日處置機率（估）25%～60% |
| 「低」 | 明日處置機率（估）5%～25% |
| 「可能」 | 明天收盤達處置觸發價就會被公布處置，但機率低於 5% 或尚未估計 |
| 「安全」 | 明天不會被公布處置：距離 2 次以上，或處置觸發價都在漲跌停之外 |

機率門檻可在設定頁「處置雷達」區調整。

### 來源標記
| 標記 | 意思 |
|---|---|
| 「官」 | 官方公告（或經 FinMind 取得的官方處置資料） |
| 「算」 | 官方名單還沒取得，本系統依規則重算 |
| 「估」 | 本系統預測 |

## 資料來源與更新時間
| 時間（交易日） | 內容 |
|---|---|
| 14:40 | 盤後初版：以收盤資料重算今天的注意、判定今晚處置、算明天的觸發價（此時還沒有分點、資券、當沖資料，機率尚未估計） |
| 18:30、19:30、21:00（預設） | 取得官方注意、處置名單後覆蓋重算結果並更新預測（需在設定頁「處置雷達」啟用官方公告來源） |
| 22:10 | 定版：資券、借券、當沖、分點到齊後補算第五、六、七、十二、十三款，算出明日處置機率與三日門檻 |
| 22:10 之後 | 重算處置歷史統計與處置配對 |

日 K、指數、分點、資券來自 FinMind；官方名單來自證交所、櫃買中心公告。

## 注意事項與限制
- 推算以公開規則為準，交易所的實際判斷可能有例外（例如監視會報決議的第十四款無法預測）。
- 存託憑證（TDR）沒有國外標的價格，第八款無法預測，只依官方注意次數判斷距離（畫面標「TDR」）。
- 官方公告來源沒有啟用時，注意股以規則重算，可能與官方有差異（頁首會提示）。
- 臨時休市時處置期間順延，畫面標「臨時休市順延」，滑過可看官方公告期間。
- 全日暫停交易的判定依 FinMind 暫停交易資料（每天 14:40、22:10 計算前與 19:00 各抓一次）；資料還沒到時，暫停日會暫時當成沒有注意的營業日，之後每晚重算最近 5 個交易日時更正。不在暫停交易資料內的停止買賣（例如減資換發）仍會中斷連續次數。
- 該股當天全日暫停交易時，「明日可能處置」與個股處置面板沿用前一營業日的次數（標「暫停交易，沿用 M/D 的次數」，跨年時帶年份）；首頁今日清單的「明天可能處置」也沿用，文字後面加「（暫停交易，沿用 M/D 的次數）」，AI 每日摘要提到時註明「暫停交易，沿用前一營業日」，個股頁首的處置徽章與旗標照樣顯示沿用的距離。選股的「排除接近處置」與處置配對的可能處置在這一天不沿用。
- 暫停日當天 17:35 以前（FinMind 的日 K 還沒入庫），以暫停交易事件判定該股當天全日暫停；收盤快照部分缺漏時，當天其實有成交、但事件涵蓋這一天的股票可能在 17:35 前被誤沿用，日 K 入庫後自動更正。非交易日一律不沿用。
- 沿用的期限順延到該股下一個營業日：事件有恢復日時以恢復日為準（例如兩天暫停，第一天看到的期限是恢復日）。前一營業日距今超過 5 個交易日（長期暫停）時不列入「明日可能處置」，個股處置面板改顯示「暫停交易中（自 M/D 起），恢復日未定，不列入明日可能處置」（恢復日已公告時寫恢復日）。
- 定版後前一營業日的列沒有明日處置機率時，沿用列以那一天三日門檻第 1 天的條件機率補回並重新分級；觸發路徑清單與量的條件的「估 N%」補不回來，會是空的。
- 三日門檻在暫停當天不沿用前一營業日：個股處置面板的三日門檻區塊顯示「該股今天全日暫停交易，當天沒有三日門檻」，三日門檻頁也沒有這檔。
- 前一營業日已公布處置、當天全日暫停的股票不沿用（處置成立後的次數無法從那一天推出），個股處置面板說明「前一營業日已公布處置」，處置期間見「目前狀態」。
