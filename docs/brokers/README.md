# 分點研究

> 位置：頂部選單「分點研究」（網址 `/brokers`，預設開啟「異常分點」分頁）
> 資料更新：分點資料每個交易日 18:10 起匯入（資料源 18:00 發布）；異常分點在當天三大法人資料到齊後（約 20:05 後）計算；交易事件、手法統計、全市場損益與分點規模每個交易日 23:50 計算

## 這個功能可以做什麼
「分點研究」從券商分點的角度整理每天的買賣資料：找出突然大量買超或賣超某檔股票的分點、依過去的交易紀錄整理出不同手法的分點排行、查詢單一分點買賣了哪些股票，並可自訂要追蹤的分點組合、分點群組與個股的關鍵分點。每個分點都有自己的分點頁，可以看它的手法統計、損益、交易事件與權證進出。

## 分點資料是什麼、能說明什麼
- **分點**是證券商的分公司（例如「凱基-台北」，代號 9268）。分點資料是每個交易日各分點在每檔股票的買入股數、賣掉股數與買賣均價，由證券交易所公布、經 FinMind 取得。
- **分點代表的是「在這家券商分公司下單成交」的買賣，不代表最終持有人。** 同一個分點裡有許多不同的投資人；外資、投信、自營商與一般投資人都可能透過同一個分點下單。分點的買超只說明「透過這個分點成交的買多於賣」，不能直接看成某一個人或某一個機構在買。
- 分點資料只有每天的合計與均價，沒有每一筆成交的時間與價格；系統計算的「損益」「報酬率」「交易事件」都是用每天的買賣均價推算，畫面上標「估」。
- 損益推算假設統計區間開始時持股為 0，並忽略手續費與交易稅。區間開始前就持有、或在其他分點賣掉的部分都看不到。
- 分點代號**區分大小寫**：例如 9A9C（永豐金-員林）與 9A9c（永豐金-永康）是不同分點。搜尋時請看清楚代號與名稱。
- 權證的分點資料同樣只代表該分點的權證買賣，不代表最終持有人；畫面上會固定顯示這句提醒。

## 共通操作
- **點分點名稱**（名稱旁的灰色小字是代號）：開啟該分點的[分點頁](broker-page.md)。
- **點股票代號與名稱**：開啟該股的「K線籌碼圖」，並自動把這個分點加入「特定分點」副圖，方便直接看這個分點在該股的進出。特定分點副圖已達上限時仍會開啟個股，並提示先移除其他分點副圖。
- 各分頁的條件（天數、方向、類別等）大多存在網址，可以加入書籤或分享網址直接重開同樣的畫面。
- 數字顏色：買超、上漲為紅色，賣超、下跌為綠色。張數 1 張＝1,000 股；金額單位為元，畫面會依大小顯示「萬」「億」。

## 名詞
- **買賣超**：買入減賣掉；正數為買超，負數為賣超。
- **交易事件**：系統依某分點在某檔股票的每日淨買，推算出的「進場到出場」一段買賣。詳見[高手分點](masters.md)。
- **手法**：依交易事件持有的交易日數分類：隔日沖（隔一個交易日就出場）、短線（2～10 日）、波段（11～120 日）。
- **贏家、輸家**：區間損益（估）最高、最低的分點。
- **隔日沖清單**：交易事件以隔日沖為主的分點清單，每晚自動產生，也可在設定頁「分點清單」手動增減；清單內的分點在各處顯示「隔」標籤。
