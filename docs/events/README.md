# 個股事件

> 位置：頂部選單「個股事件」（網址 `/events`，預設開啟「事件行事曆」分頁）；手機在底部「更多」裡
> 資料更新：事件樣本每個交易日 15:40（收盤資料後）與 22:40（營收、股利入庫後）增量更新，週日 04:00 全部重建一次；法說會、股東會、庫藏股決議與月營收、財報的官方公布時間每天 08:00、16:00、22:00 向官方開放資料抓取（時間可在設定頁修改）

## 這個功能可以做什麼
個股事件把除權息、月營收公布、財報公布、減資恢復買賣、處置開始與結束、列為注意股、停止融券、暫停當沖、暫停交易後恢復、法說會、股東會、庫藏股決議等事件，整理成每檔股票、每種事件的**歷史統計**：事件前後每天的漲跌、上漲機率、平均與中位數報酬、相對大盤的超額報酬，以及自訂進場與出場時點（T−20～T+20、開盤或收盤）扣除成本後的報酬。

- 想知道未來 30 天有哪些事件、每一筆過去的表現：看「事件行事曆」。
- 想比較除權息的權值率、息值率、填息機率：看「除權息」。
- 想用自己的規則回測一種事件的歷史表現：看「事件回測」。
- 想比較各股票同一種事件的歷史統計：看「歷史上漲機率排序」。

每一頁下方固定註明「歷史統計不代表未來結果」。本功能只整理歷史資料，不構成任何操作依據。

## 共同用語
- **事件日 T**：一律是交易日。事件日不是交易日時順延到下一個交易日；盤後公布的事件（例如月營收）以公布日的下一個交易日為 T。
- **區間**：進場與出場相對 T 的交易日位移，加上用開盤或收盤，例如「T−1 收盤→T+3 收盤」。常用預設有「事件前 3 日」「T−1 收→T 開」「T 開→T 收」「T 收→T+3 收」「T−3→T+3」「T−1 收→T+3 收」（預設），也可以「自訂」。同一天只能開盤進場、收盤出場。
- **N**：有效樣本數。畫面上每個比例旁都標 N；N 少於 5 時標「樣本少」，不列入排序。
- **上漲機率**：淨報酬大於 0 的比例。
- **調整後上漲機率（估）**：（上漲次數 ＋ 10 × 全市場同種事件的上漲機率）÷（N ＋ 10）。樣本少時會向全市場的上漲機率靠攏，避免少數幾筆就顯示很高的比例。
- **超額平均**：每一筆（淨報酬 − 同區間大盤含息報酬指數的報酬）的平均。
- **近年改變**：最近 3 年與更早相比，上漲機率相差 15 個百分點以上，或平均報酬正負號相反（兩段都要有 5 筆以上）。
- **成本**：「扣成本」（預設）扣除手續費（含折扣與最低手續費）、證交稅（股票 0.3%、ETF 0.1%，出場時）、每邊滑價，以及持有期間跨過除息日時的股利所得稅；「不扣成本」看毛報酬。手續費折數、滑價與股利所得稅率沿用策略實驗室與期現套利的系統設定，頁面會列出實際採用的值。
- **含息／不含息**：「含息」（預設）在除權息日以參考價還原，等同股利再投入；「不含息」只看股價，不計入現金股利。
- **估**：推算的事件日（沒有官方公布時間也沒有入庫時間的月營收、未來的月營收、沒有官方公布時間的財報）與以最新收盤估算的除權息指標都標「估」；所有統計本身也是歷史估計。
- **公布時間**：月營收與財報實際公布的時間與來源。有官方開放資料的時間時以官方為準，沒有時用 FinMind 入庫日，都沒有時依規則推算並標「估」。事件日 T 依公布時間決定：09:00 前公布為當天，09:00 以後（含盤中）為下一個交易日；只有日期時當作收盤後公布。
- **待核對**：官方開放資料與 FinMind 的月營收數值不一致、官方有而 FinMind 還沒有，或日期互相矛盾時，在公布時間旁加小標記「待核對」。統計的數值一律以 FinMind 為準。

## 資料來源與更新時間
| 資料 | 來源 | 更新 |
|---|---|---|
| 除權息、減資、分割、面額變更、暫停交易、停止融券、暫停當沖 | FinMind（官方公告資料） | 交易日 15:40、22:40 |
| 月營收公布日 | 官方開放資料（證交所、櫃買中心月營收彙總表）第一次出現這家公司這個月營收的檔案更新時間；沒有時用月營收入庫時間（2026-04-21 起）；更早以每月 10 日推算（遇假日順延，標「估」） | 官方資料每天 08:00、16:00、22:00；入庫時間交易日 22:40 |
| 財報公布日 | 官方開放資料每日重大訊息裡財務報告公告的發言時間（隔天才取得）；在那之前與沒有公告時依法定申報期限或 FinMind 可取得日推算（標「估」） | 每天 08:00、16:00、22:00 |
| 法說會、庫藏股決議 | 官方開放資料的每日重大訊息（法人說明會、董事會決議買回庫藏股的公告） | 每天 08:00、16:00、22:00 |
| 股東會 | 官方開放資料的股東會資料（日期、地點、是否改選董監）與每日重大訊息的召集公告 | 每天 08:00、16:00、22:00 |
| 處置、注意股 | 處置雷達的官方名單 | 交易日 22:40 |
| 大盤報酬 | 加權報酬指數（含息） | 交易日 15:40 |

## 注意事項與限制
- 法說會、股東會、庫藏股決議來自證交所與櫃買中心的官方開放資料，**沒有更早的歷史**：資料從設定頁開啟「官方開放資料事件來源」那天起累積（股東會開啟當天就有當年度的清單）。畫面上這三種事件註明「資料自 YYYY-MM-DD 起累積」；剛開始樣本很少，統計卡會標「樣本少」。
- 「官方開放資料事件來源」預設關閉；關閉時不向來源發送任何請求，這三種事件沒有新資料，月營收與財報維持原本的公布日規則。設定見[設定](../settings.md#官方開放資料事件來源)，各來源的狀態見[系統（資料狀態）](../system.md)。
- 月營收、財報改用官方公布時間後，部分樣本的事件日 T 會往前一天（09:00 前公布）或改成實際日期，統計數字會跟著改變。
- K 線圖的事件標記目前不含法說會、股東會、庫藏股決議。
- 分割、反分割、面額變更只列在行事曆，不做統計（價格結構改變）。
- 持有區間內有分割、減資、面額變更或連續 2 日以上沒有交易的事件會被剔除；同一檔同一種事件 5 個交易日內重複時只取第一筆。
- 一字漲停或一字跌停的日子無法進出，會順延一天並計數。
- 樣本很少的統計參考性低；請一併看 N 與「近年改變」。

## 在策略選股使用

策略選股的「事件」分類有「未來 N 日內事件」與「最近 N 日內事件」兩條條件，事件種類可多選（有其中一種就成立）；未來事件只用資料日當天已知的消息。說明見[策略選股｜條件總表](../screener/conditions.md#事件8-條)。

## 連到權證時的「事件短天期」篩選

從行事曆、除權息、排行或個股「事件」子分頁點權證數，會開啟該股的權證子分頁並套用「事件短天期」篩選：剩餘交易日 40 日以內、價內外 −10%～+10%。篩選只列出資料，可以在權證子分頁修改或按「清除條件」取消。
